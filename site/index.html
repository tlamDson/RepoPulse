The gold tables are refreshed by an hourly incremental batch (not real-time) and this page is rebuilt after each successful run. Every number on it is read from the exported data files; nothing is typed by hand. This page shows no simulated data: a section built from the simulated app event stream would carry the label "simulated".

Q1 · Daily active contributors

Human contributors active each day, per repo category (pull requests, reviews, issues and comments; bots excluded). The table lists the same values; repo-level and weekly rows are in the CSV.

Download CSV (Tableau)

Q2 · Cohort retention

Cohort = ISO week of a contributor's first pull request on a tracked repo. Share of the cohort active again exactly at week W+4 and W+12.

Download CSV (Tableau)

Q3 · Contribution funnel

Fork, then pull request opened, then merged, per repo. The chart shows the repos with the most pull requests opened; the table lists every repo.

Download CSV (Tableau)

Q4 · Responsiveness

Median hours to the first human response on issues and pull requests, per repo. The chart shows the repos with the most opened items; the table lists every repo.

Download CSV (Tableau)

Q5 · Contributor concentration

Share of human contributions made by the single most active contributor (bus factor). The chart shows the repos with the most contributions; the table lists every repo.

Download CSV (Tableau)

Q6 · Repo health score

Composite score from the Q1 to Q5 components, ranked. The chart shows the top of the ranking; the table lists every repo and component.

Download CSV (Tableau)

Runs (runs.csv)

Every measured run: benchmarks, scale tests and dbt builds. Times are only comparable between rows of the same data date and query set.
